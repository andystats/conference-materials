When the true data-generating process follows a directed acyclic graph (DAG), features proximal to the outcome node in the causal graph absorb disproportionate attribution credit. A downstream mediator like "blood pressure at admission" will appear enormously important even though it is largely determined by upstream causes like diet, genetics, or socioeconomic factors. This is a topological artifact, not a reflection of genuine causal contribution.### 1.2 Causal SHAP as a CorrectiveSeveral authors have proposed modifying the Shapley value framework to respect causal structure. The core insight is that feature importance should be computed under interventional rather than observational distributions Ñ using Pearl's do-operator Ñ so that credit is allocated according to causal pathways rather than mere statistical association.Key theoretical contributions include Heskes et al. (2020), who formalized "Causal Shapley values" by defining coalition-conditional expectations via interventions on a known causal DAG; Janzing et al. (2020), who proposed quantifying feature relevance by contrasting observational and interventional distributions; and Wang et al. (2021), who connected Shapley-based attribution to path-specific causal effects.### 1.3 Knuth's TREEPROBS and the Computational AngleThe tractability of Bayesian inference on tree-structured graphical models has been studied extensively. Knuth's TREEPROBS program (2011) demonstrates that for binary tree networks, the "frontier" of unresolved variables at any step is bounded by ?log?(n+1)?, enabling efficient computation of arbitrary Boolean queries over the joint distribution. This log-depth frontier bound is analogous to the low-treewidth conditions that make exact inference tractable in probabilistic graphical models, and motivates the feasibility of DAG-structured attribution even in moderately large feature spaces.### 1.4 Existing Software**Python:** `fast-causal-shap` (Ng et al., 2025; PyPI v0.3.0, MIT License) accepts a causal graph as an external JSON input (directed edge pairs with estimated mean causal effects) and adjusts SHAP value computation accordingly. It supports integration with PC, IDA, and FCI causal discovery algorithms. The causal graph is modular Ñ any DAG can be supplied regardless of how it was produced.**R:** `shapcf` (Koh, in review; GitHub, GPL-3) implements Shapley values for causal forests via the `grf` package. It provides SVCF (local contribution to individual treatment effects) and SFICF (global feature importance), with visualization tools for beeswarm, waterfall, and bar plots. Example datasets include microbiome studies of e-cigarette use, antibiotic treatment, and cancer immunotherapy.### 1.5 The Gap: Expert-Augmented Causal DiscoveryCurrent tools either rely entirely on algorithmic causal discovery (PC, FCI) Ñ which often returns partially oriented CPDAGs with ambiguous edges Ñ or require a fully specified DAG from the user. In applied epidemiology, the most common and most credible workflow is hybrid: data-driven discovery provides a structural skeleton, and domain expertise resolves ambiguous orientations based on temporal ordering, biological plausibility, and prior experimental evidence. No existing tool formalizes this iterative, expert-in-the-loop refinement process for the purpose of causally-adjusted feature attribution.---## Part 2: Proposed Workflow### Stage 1: Data-Driven Skeleton DiscoveryRun the PC or FCI algorithm on observed data to obtain a CPDAG (completed partially directed acyclic graph). This provides the adjacency structure and orients edges where v-structures or orientation rules are unambiguous.### Stage 2: Expert ResolutionUsing tools like `dagitty` (Textor et al., 2016), an epidemiologist resolves remaining undirected edges based on domain knowledge. The resolved DAG's implied conditional independencies can be tested against data to verify consistency.### Stage 3: Edge Weight EstimationEstimate the causal effect for each directed edge using structural equation model coefficients, IDA estimates from `pcalg`, or targeted learning methods. Export as JSON in the format required by `fast-causal-shap`.### Stage 4: Causal SHAP ComputationLoad the resolved DAG into `fast-causal-shap` and compute adjusted SHAP values. Compare to standard (DAG-agnostic) SHAP values.### Stage 5: Sensitivity AnalysisRepeat Stages 2Ð4 under alternative plausible DAG specifications to assess robustness of feature importance rankings.---## Part 3: Simulation Design### 3.1 Data-Generating ProcessSimulate data from a known DAG with n=2000 observations and p=10 features:- **X1, X2** ~ N(0,1) [root causes]- **X3** = 0.7áX1 + ??
