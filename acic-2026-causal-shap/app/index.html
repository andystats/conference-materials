Run the full workflow

Try causal SHAP on your own CSV.

The hosted conference page is static. The full causal discovery and causal SHAP workflow runs as a local Python Shiny app.

Quick Start

From the acic-2026-causal-shap/app/ folder:

py -3.13 -m pip install -r requirements.txt py -3.13 -m shiny run --port 8000 app.py

Then open http://127.0.0.1:8000. On Windows, run_app.bat does the same thing.

Workflow

1. Upload Data Use a CSV with one row per observation and numeric columns for candidate features and outcome.
2. Resolve the DAG Run discovery, then add required and forbidden edges from temporal and domain knowledge.
3. Compare Attribution Run standard SHAP, DAG-constrained causal SHAP, and adjustment-set SHAP.

What To Bring

  • A prediction outcome column.
  • Candidate feature columns.
  • Enough subject-matter knowledge to rule out impossible arrows.
  • A willingness to treat the output as attribution under assumptions, not proof of causality.
