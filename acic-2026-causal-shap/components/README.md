# Components

Reusable HTML/JSX snippets for this conference's dashboard and poster. Snippets here are meant to be pasted into the dashboard `index.html` or into PowerPoint shapes that the user assembles into the printed poster.

**Filename convention:** `<kebab-case-name>.html` (or `.jsx` for React fragments).

**Example (future):** `rank-movement-card.html` — the feature-rank slope graph as a standalone HTML block.

Empty until real poster work drives the first component.
