# Text

Plain Markdown fragments for poster sections. Each file is one section — headline, abstract, a single column, a caption, etc. The user composes the printed poster from these in PowerPoint.

**Filename convention:** `<section>.md` — e.g. `headline.md`, `abstract.md`, `column-left.md`, `fig-hero-caption.md`.

Empty until the first real section is lifted out of the poster draft.
